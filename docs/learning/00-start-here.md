# Start here — read in this order

If you're new to voice AI, read these four files top to bottom. About 30 minutes total.

1. **[01 — what a voice agent actually is](./01-what-is-a-voice-agent.md)**
   The five moving parts, why the industry is going nuts about this, and what makes it hard.

2. **[02 — glossary](./02-glossary.md)**
   Every acronym (STT, TTS, VAD, SIP, µ-law, WebRTC, MOS...) explained plainly. Bookmark this — you'll come back.

3. **[03 — the repo in one page](./03-repo-mental-model.md)**
   How everything you have on disk maps to the five moving parts. Where to look when something breaks.

4. **[04 — reading list](./04-reading-list.md)**
   Actual URLs to blogs, papers, docs, and repos worth your time. Ranked, with what to skip.

Then jump into the topic-specific docs already in `docs/`:
- `vapi-setup.md`, `channels-setup.md`, `twilio-setup.md` — how to hook up each transport
- `qwen3-tts-setup.md`, `elevenlabs-setup.md` — how to hook up each voice
- `ghl-setup.md`, `google-setup.md` — how to hook up each CRM
- `provider-matrix.md` — which combo to pick per client

**One line to remember:** the brain is the product, everything else is a swap.
