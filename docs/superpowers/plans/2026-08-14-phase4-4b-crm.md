# PHASE 4b — CRM Adapters (HubSpot / Salesforce / Zoho on top of GHL)

**Goal:** post-call outcomes flow into whichever CRM the client already uses. Not just booking receipts — full outcome payloads (caller name, phone, intent, tags, transcript excerpt, follow-up flag).

**Position:** commercial requirement. Doc #56 line 155. Bare-minimum for most Upwork gigs.

## Prereqs
- PHASE4a done (real bookings to sync)
- Outcome Engine from doc #55 §Outcome Engine (may need to build first — see Task 1)

## Global Constraints
- **GHL adapter already exists** at `packages/integrations/ghl_client.py`. Reuse patterns from it.
- **Adapter interface uniform across CRMs.** All 4 CRMs implement `CRMAdapter` protocol; downstream code doesn't care which one.
- **Failures don't block the call.** CRM sync happens post-call in a queue. Retry with exponential backoff. Never make the caller wait for HubSpot.
- **Field mapping is per-tenant.** Different clients want different fields; ship a `field_map.yaml` per tenant.
- **PII redaction pre-CRM.** Same regex pipeline used for stored transcripts — don't ship raw SSNs / card numbers to third-party CRMs.

## File Structure

- `packages/integrations/crm/base.py` — `CRMAdapter` protocol + `OutcomePayload` dataclass
- `packages/integrations/crm/hubspot.py`
- `packages/integrations/crm/salesforce.py`
- `packages/integrations/crm/zoho.py`
- `packages/integrations/crm/router.py` — pick from `BusinessProfile.crm_provider`
- `packages/integrations/crm/queue.py` — outbound sync queue (retry + backoff)
- `packages/core_agent/outcome_engine.py` — build the payload from CallState + tool_results
